# 💰 Expense Tracker Analysis – Personal Finance Management System

A modern SaaS-style Personal Finance Dashboard built using Vanilla JavaScript, Chart.js, and jsPDF.

---

## 🚀 Overview

Finance Dashboard is a professional personal finance management system that allows users to:

- Track income and expenses
- Manage multiple accounts (Cash, Bank, Credit Card)
- Set category-wise budgets
- Track savings goals
- View financial insights
- Analyze monthly trends
- Export reports (CSV & PDF)

This project is designed with a clean SaaS-style UI and structured dashboard layout.

---

## ✨ Features

### 💳 Multi-Account Management
- Track transactions across:
  - Cash
  - Bank
  - Credit Card
- View consolidated balance
- Monitor account-level performance

### 📊 Advanced Analytics
- Monthly income vs expense chart
- Category breakdown pie chart

- Animated charts using Chart.js

### 🎯 Savings Goal Tracker
- Create custom savings goals
- Track saved vs target amount
- View progress percentage

### 💰 Budget Management
- Set monthly budgets

- Budget exceeded alerts

### 🧠 Smart Financial Insights
- Savings rate calculation
- Income vs expense breakdown

### 📅 Date Filtering
- Filter transactions by date range

### 📁 Export System
- Export transactions to CSV
- Generate PDF financial report
